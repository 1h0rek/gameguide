# GameGuide

Простая первая версия сайта с гайдами по играм.

## Запуск

1. Распакуй папку.
2. Открой `index.html` в браузере.

Для XAMPP:
1. Положи папку `gameguide` в `C:\xampp\htdocs\`.
2. Запусти Apache.
3. Открой `http://localhost/gameguide/`.

## Что уже есть

- главная страница;
- список игр;
- список гайдов;
- поиск по играм и гайдам;
- адаптация под телефон;
- кнопки магазина;
- место для будущей рекламы и партнёрских ссылок.

## Монетизация

Ссылки на магазин сейчас демонстрационные. После регистрации в партнёрской программе их можно заменить на свои партнёрские ссылки.

Следующий этап можно сделать с отдельными страницами:
`game.html`, `guide.html`, категории, SEO и рекламные блоки.
